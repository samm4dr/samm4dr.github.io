Scrape Kalshi Prediction Markets: Odds, Volume & Weather Markets via API

Kalshi is the regulated US prediction market — election odds, Fed decisions, economic prints, even weather markets. Its public API exists but is rate-limited and awkward for bulk history. This tutorial shows the Apify-actor pipeline: markets, order books, and cross-platform arbitrage with Polymarket.

The stack

  • Apify — Kalshi actors for markets, odds, volume, profiles. Free monthly credits included.

Step 1 — Get your API token

  1. Create an Apify account (free credits included)
  2. Console → Settings → Integrations → copy your API token
  3. export APIFY_TOKEN=your_token

Step 2 — Pull market data

curl -X POST "https://api.apify.com/v2/acts/scrapemint~kalshi-prediction-market-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"category": "economics", "maxItems": 100}'

Fields per market: ticker, title, yesPrice, noPrice, volume, openInterest, closeTime, url.

Step 3 — Build an odds feed

from apify_client import ApifyClient

client = ApifyClient("APIFY_TOKEN")
run = client.actor("scrapemint/kalshi-prediction-market-scraper").call(run_input={
    "category": "economics", "maxItems": 200
})

for m in client.dataset(run["defaultDatasetId"]).iterate_items():
    yes = m.get("yesPrice") or 0
    print(f"{m.get('title', '')[:65]:65s} YES={yes:>4.2f} vol={m.get('volume', 0)}")

Schedule it in Apify Console → snapshots → price-movement alerts.
