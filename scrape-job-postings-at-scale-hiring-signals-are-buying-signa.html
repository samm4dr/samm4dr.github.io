Scrape Job Postings at Scale: Hiring Signals Are Buying Signals

Companies posting jobs are revealing exactly what they need — in real time. A company hiring "SEO specialist" needs SEO help. Five sales openings mean they want pipeline. Hiring a "migration engineer"? They need a dev agency.

Here's how to turn public job boards into a lead-gen machine using Apify actors — no scraper maintenance, no proxy bills.

The stack

  • Apify — ready-made actors for Google Jobs, Indeed, and LinkedIn. Free monthly credits included.
  • Python + apify_client — 20 lines to a clean CSV.

Step 1 — Token

Create an Apify account → Console → Settings → Integrations → copy the API token → export APIFY_TOKEN=...

Step 2 — Run the Google Jobs actor

curl -X POST "https://api.apify.com/v2/acts/apify~google-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "queries": "remote react developer",
    "countryCode": "us",
    "maxPagesPerQuery": 2
  }'

Output fields: title, companyName, location, salary, description, applyUrl, postedAt.

Step 3 — Hiring-signal filter

from apify_client import ApifyClient

client = ApifyClient("APIFY_TOKEN")
run = client.actor("apify/google-jobs-scraper").call(run_input={
    "queries": "seo specialist\ncontent writer\nppc manager",
    "countryCode": "us",
    "maxPagesPerQuery": 1,
})

signals = {}
for job in client.dataset(run["defaultDatasetId"]).iterate_items():
    company = job.get("companyName", "")
    signals.setdefault(company, []).append(job.get("title"))

# Companies hiring multiple roles = hot prospects
for c, titles in signals.items():
    if len(titles) >= 2:
        print(f"{c}: {len(titles)} openings -> {titles[:3]}")

The lead-gen play

  1. Schedule the actor daily in Apify Console
  2. Filter new postings per company
  3. Enrich the company domain with vdrmota/contact-info-scraper (emails, socials)
  4. Outreach: "Saw you're hiring for X — we deliver that as a service today"

Companies hiring are companies with budget. You're not cold-calling — you're showing up exactly when the pain is public.
